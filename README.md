# NTO_2k26
COEX CLOVER one love


Пошаговая инструкция:
1. В терминал на симуляторе необходимо ввести: git clone https://github.com/indi-afk/vovchik_lovit_2k26
2. Перейти в директорию vovchik_lovit_2k26
3. Запустить программу setting.py. Это можно сделать с помощью команды python3.
4. Открыть симулятор Gazebo
5. Запустить программу pipe_spawn.py. Это можно сделать с помощью команды python3.
6. Дождавшись, когда появилась труба и врезки, запустить программу flying.py
